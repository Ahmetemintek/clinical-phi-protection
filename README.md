## Dataset

This project uses the [ASQ-PHI dataset](https://github.com/JamesWeatherhead/asq-phi), developed by James Weatherhead, George Golovko, and Peter McCaffrey.

ASQ-PHI is a synthetic clinical-query benchmark containing 1,051 queries with PHI annotations.

- **License:** MIT
- **Source:** https://github.com/JamesWeatherhead/asq-phi
- **Citation:** Weatherhead, J., Golovko, G., & McCaffrey, P. (2026). *ASQ-PHI: An adversarial synthetic data benchmark for clinical de-identification and search utility*. Data in Brief, 65, 112586. https://doi.org/10.1016/j.dib.2026.112586

The dataset was processed for character-offset reconstruction. Original annotations and source queries were preserved.
